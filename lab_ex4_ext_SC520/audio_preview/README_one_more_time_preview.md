# One More Time — 无源蜂鸣器单音试听（近似/灵感示例）

## 重要声明（必须先读）

- 这个 WAV **不是**对 Daft Punk《One More Time》原曲的忠实还原，也**不是**
  经过可靠乐谱/MIDI 核对的音符转录。
- 本次会话没有核实到可信的原曲旋律音符资料；文件是**近似/灵感示例**：
  借用了歌曲大约 123 BPM 的节奏感和 B 小调五声音阶（B-D-E-F#-A）的
  上行/下行轮廓，旋律音符与节奏是自行改编的。
- 如果后续拿到可靠谱例，应以实际谱例重新生成；在此之前不要把它当作
  “原曲旋律”使用。
- 仅用于无源蜂鸣器的单音试听。**蜂鸣器尚未接线、类型（有源/无源）尚未
  核实**；本文件不构成硬件已验证结论。无源蜂鸣器应由方波驱动，实际响度
  取决于其谐振频率与驱动电路。

## 文件

- 试听 WAV：`lab_ex4_ext_SC520/audio_preview/one_more_time_approx_buzzer.wav`
- 生成脚本：`lab_ex4_ext_SC520/audio_preview/gen_one_more_time_preview.py`
  （仅 Python 标准库 `wave`/`struct`/`math`，无需安装新软件）
- 格式：单声道，16-bit PCM，22050 Hz；同一时刻只有一个方波音符；
  每音 5 ms attack / 5 ms release，音间 25 ms 间隙。

## 旋律依据（近似）

- 速度：123 BPM（≈0.4878 s/拍）。
- 调性/音集：B 小调五声（B-D-E-F#-A）的轮廓，实际使用的音高为
  F#5/A5/B5/C#6/D6（740–1175 Hz），适合无源蜂鸣器的中高频段试听。
- 结构：按“主歌 hook 的句子长度”分成 4 个短句 + 一次短重复，
  不是对原曲逐个音符的转写。

## 参考工程 `D:\FPGA\buzzer_example\13_music`（只读参考，未修改）

- `a.adc`：`spk` → **C12**，LVCMOS33，DRIVESTRENGTH=8。
- `clk_divide.v`：50MHz → `c0=1MHz`、`c1=4Hz`。
- `SONG.v`：`CNT138T` 在 4Hz 下扫描地址 0..138（139 个 0.25s 槽位，
  约 34.75s 一循环），4-bit ROM 输出音符索引；`F_CODE` 映射到
  LED/高音标志/11-bit `TN`；`SPKER`+DFF 在 `spk` 上产生方波。
- `SPKER.v`：1MHz 计数，`CNT11==0x7FF` 时 `SPKS` 脉冲并重装 `TN`；
  DFF 翻转输出，方波频率
  **f = 1MHz / (2 × (2048 − TN))**。
- `F_CODE`：索引 0=休止；1..15 约 G4(≈392Hz) 到 G6(≈1563Hz)。
  本试听用到的 F#5/A5/B5/C#6/D6 对应其索引 **7/9/10/11/12**
  （频率接近；该表是其工程自己的近似值）。
- 该样例的音符时值是 0.25s 槽位的整数倍；本 WAV 是独立试听，
  不是该工程的驱动，也没有把蜂鸣器驱动加入本 FPGA 工程。
- 参考样例仅用于确认“无源蜂鸣器由可变频方波驱动”及音域/引脚；
  **蜂鸣器有源/无源与实际接线仍需用户确认**。
